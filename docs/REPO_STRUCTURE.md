## Structural Rationale

| Area | Reason |
|---|---|
| `NLPCC_tasks/` | Preserve the official starter kit and server/client reference implementation. |
| `src/nlpcc/` | Main competition implementation that the submitted agent should call. |
| `src/tools/` | Local research/dev tools that should not pollute the production package. |
| stage `models/` subfolders | Preserve multiple candidate models without mixing them with pipeline orchestration. |
| `docs/prompts/execution/` | Store the numbered execution prompts used by coding agents. |
| `docs/implementation_logs/` | Store logs from `create_implementation_log`. |
| `outputs/` | Store generated experiment artifacts; do not commit large outputs unless explicitly intended. |
